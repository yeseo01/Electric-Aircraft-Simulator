# CSV 입력을 위로 옮기고 3D 공간 넓히기

이번 변경은 API 데이터를 계산하는 방식이 아니라 **같은 데이터를 화면에 배치하는 방식**을 바꾼 것이다.

```text
┌────────────────┬──────────────────────────────────────────────────┐
│   CSV 입력     │                                                  │
├────────────────┤                                                  │
│   2D 경로      │                                                  │
├────────────────┤                  3D 경로                         │
│   고도 플롯    │                                                  │
├────────────────┴──────────────────────────────────────────────────┤
│                         결과 요약                                 │
└───────────────────────────────────────────────────────────────────┘
```

## CSS Grid로 영역 정하기

`App.tsx`에서 CSV 입력과 차트 세 개를 같은 `workspace-grid` 안에 둔다.
`App.css`에서 CSV 입력을 왼쪽 열의 첫 행으로 지정해 2D 창과 너비를 맞춘다.
결과 요약은 그리드 아래에 별도로 둔다.

```css
.workspace-grid {
  display: grid;
  grid-template-columns: minmax(280px, 1fr) minmax(0, 2.15fr);
  grid-template-rows: auto repeat(2, minmax(0, 1fr));
  grid-template-areas:
    'mission  spatial'
    'route    spatial'
    'altitude spatial';
}
```

첫 행의 `auto`는 CSV 입력에 필요한 높이만 사용한다. `1fr` 두 행은 나머지 높이를
반씩 나눈다. `spatial`이 세 행에 반복되므로 3D 패널이 CSV 입력 위쪽부터 고도 플롯
아래쪽까지 이어진다. 오른쪽 열은 왼쪽의 2.15배로, 이전 2D·3D를
합친 정도의 너비를 확보한다. `minmax(0, …)`는 긴 내용이 그리드를 억지로 늘리지 않게 한다.

차트 내부는 Flexbox의 `flex: 1`로 제목과 설명을 제외한 공간을 채운다. 기존
`ResizeObserver`가 바뀐 크기를 감지해 ECharts와 Plotly를 다시 맞춘다.

## CSV 입력을 작게 만들기

CSV 입력 폭은 2D 창과 같다. `CsvFilePicker`에 선택적 `compact` prop을 추가해,
파일 선택 후에는 파일명·변경·삭제를 드롭 영역 한 줄 안에 모았다. 그 아래에
Generate preview 버튼과 상태·도움말을 둔다. 긴 파일명은
줄임표로 표시하고 마우스를 올리면 전체 이름을 볼 수 있다. 파일 검증과 업로드 버튼의
동작은 기존과 같다. 설명은 HTML `<details>` / `<summary>`로 접어 두고 필요할 때 펼친다.
잘못된 파일이나 API 오류는 접힌 설명 밖에 바로 표시한다.

## 좁은 화면 대응

1000px 이하에서는 CSV → 2D → 고도 → 3D 순서로 쌓는다. 600px 이하에서는 CSV
버튼도 한 열로 쌓아 가로 스크롤 없이 사용할 수 있게 한다.

수정 파일은 `App.tsx`, `App.css`, 긴 파일명 설명을 추가한 `CsvFilePicker.tsx`다.
기존 업로드·재시도·취소 테스트와 빌드를 실행하고, 합성 데이터로 실제 차트 배치와
CSV와 2D 창의 같은 너비, 왼쪽 두 차트의 같은 높이, 3D의 세 행 확장,
좁은 화면의 가로 넘침을 확인한다.
