# CSV 입력을 위로 옮기고 3D 공간 넓히기

이번 변경은 API 데이터를 계산하는 방식이 아니라 **같은 데이터를 화면에 배치하는 방식**을 바꾼 것이다.

```text
┌────────────────┬──────────────────────────────────────────────────┐
│   CSV 입력     │                                                  │
├────────────────┤                                                  │
│   2D 경로      │                                                  │
├────────────────┤                  3D 경로                         │
│   고도 플롯    │                                                  │
├────────────────┴──────────────────────────────────────────────────┤
│                         결과 요약                                 │
└───────────────────────────────────────────────────────────────────┘
```

## CSS Grid로 영역 정하기

`App.tsx`에서 CSV 입력과 차트 세 개를 같은 `workspace-grid` 안에 둔다.
`App.css`에서 CSV 입력을 왼쪽 열의 첫 행으로 지정해 2D 창과 너비를 맞춘다.
결과 요약은 그리드 아래에 별도로 둔다.

```css
.workspace-grid {
  display: grid;
  grid-template-columns: minmax(280px, 1fr) minmax(0, 2.15fr);
  grid-template-rows: auto repeat(2, minmax(0, 1fr));
  grid-template-areas:
    'mission  spatial'
    'route    spatial'
    'altitude spatial';
}
```

첫 행의 `auto`는 CSV 입력에 필요한 높이만 사용한다. `1fr` 두 행은 나머지 높이를
반씩 나눈다. `spatial`이 세 행에 반복되므로 3D 패널이 CSV 입력 위쪽부터 고도 플롯
아래쪽까지 이어진다. 오른쪽 열은 왼쪽의 2.15배로, 이전 2D·3D를
합친 정도의 너비를 확보한다. `minmax(0, …)`는 긴 내용이 그리드를 억지로 늘리지 않게 한다.

차트 내부는 Flexbox의 `flex: 1`로 제목과 설명을 제외한 공간을 채운다. 기존
`ResizeObserver`가 바뀐 크기를 감지해 ECharts와 Plotly를 다시 맞춘다.

## CSV 입력을 작게 만들기

CSV 입력 폭은 2D 창과 같다. `CsvFilePicker`에 선택적 `compact` prop을 추가해,
파일 선택 후에는 파일명·변경·삭제를 드롭 영역 한 줄 안에 모았다. 그 아래에
Generate preview 버튼과 상태·도움말을 둔다. 긴 파일명은
줄임표로 표시하고 마우스를 올리면 전체 이름을 볼 수 있다. 파일 검증과 업로드 버튼의
동작은 기존과 같다. 설명은 HTML `<details>` / `<summary>`로 접어 두고 필요할 때 펼친다.
잘못된 파일이나 API 오류는 접힌 설명 밖에 바로 표시한다.

CSV 패널의 글씨는 `text-align: center`로 가운데 정렬한다. 제목과 실행 버튼처럼
Flexbox인 요소는 `justify-content: center`도 지정한다. 실행 버튼의 화살표는 오른쪽에
별도로 배치해 버튼 글씨 자체가 가운데에 오도록 했다.

## 한 화면 안에 맞추기

차트에만 840px 이상의 높이를 주면 헤더·제목·요약이 더해져 화면 아래로 넘친다.
데스크톱에서는 `.app`을 `100dvh`(현재 브라우저 콘텐츠 영역 높이)로 두고, 바깥쪽
10px 여백을 제외한 높이를 `.dashboard`가 사용하게 했다.

```css
.dashboard {
  display: grid;
  height: 100%;
  grid-template-rows: 42px 46px minmax(0, 1fr) 54px 18px;
}
.workspace-grid {
  height: auto;
  min-height: 0;
}
```

각 행은 헤더·제목·차트·요약·하단이다. `minmax(0, 1fr)`인 차트 행이 남은 높이를
사용한다. 차트 고정 높이와 큰 여백은 이 모드에서 해제한다. `overflow: hidden`으로
페이지 아래를 가리는 방식이 아니므로 모든 패널을 실제 화면 안에 배치한다.
CSV 도움말·오류가 길어지면 CSV 패널 안에서 스크롤할 수 있다.

작아진 플롯에서도 선이 보이도록 ECharts의 축 여백도 줄였다. 평면 경로는
같은 `routeGrid` 값을 그리기와 축 범위 계산에 함께 사용해 동·북 미터 축척을 유지한다.
고도 플롯은 축과 시간 확대 슬라이더 사이 여백을 줄이고 슬라이더 기능은 유지한다.

이 배치는 너비 1000px 초과·높이 680px 이상의 데스크톱 화면에 적용한다.
더 좁거나 낮은 화면에서는 내용을 과도하게 압축하지 않고 기존 스크롤 배치를 사용한다.

## 좁은 화면 대응

1000px 이하에서는 CSV → 2D → 고도 → 3D 순서로 쌓는다. 600px 이하에서는 CSV
버튼도 한 열로 쌓아 가로 스크롤 없이 사용할 수 있게 한다.

배치 파일은 `App.tsx`, `App.css`이며 입력은 `CsvFilePicker.tsx`,
차트 내부 여백과 같은 미터 축척 계산은 `chartOptions.ts`에 있다.
기존 업로드·재시도·취소 테스트와 빌드를 실행하고, 합성 데이터로 실제 차트 배치와
CSV와 2D 창의 같은 너비, 왼쪽 두 차트의 같은 높이, 3D의 세 행 확장,
좁은 화면의 가로 넘침을 확인한다.
